# 모아(MOA) — 덜 읽고, 더 알기

여러 뉴스레터를 읽고 중복을 합쳐 한국어로 정리한 뒤 Notion에 기록하는 모닝 다이제스트 실행 저장소.

## 구성
- `.claude/skills/moa-digest/SKILL.md`: 매일 실행되는 지시문 전체 (수정은 이 파일에서)
- `CLAUDE.md`: 저장소 안내

## 사용
Claude Code 루틴(`claude.ai/code/routines`)에 이 저장소를 연결하고, 루틴 프롬프트는 `moa-claude-code-guide.md`의 "루틴 프롬프트"를 그대로 붙여넣는다.
설정값(Notion 페이지 주소 등)은 `SKILL.md` 맨 위의 "설정" 항목에 있다.
